Kompozícia
skladanie objektov

Objekt sa skladá z iných objektov. Ako auto, ktoré má motor a štyri kolesá.

Objednávka má zákazníka a má zoznam produktov.

Kompozícia = vzťah „má“ (has-a). Objednávka má zákazníka, objednávka má produkty. Môžete sa opýtať triedy na ďalšie príklady: auto má motor, škola má triedy, playlist má skladby.

Trieda AProdukttovar v obchode

public class Produkt
{
    public string Nazov;
    public double Cena;

    // Výpis informácií o produkte
    public string DajInfo()
    {
        return $"{Nazov} ({Cena} EUR)";
    }
}
Trieda BZakaznikčlovek, ktorý nakupuje

public class Zakaznik
{
    public string Meno;
    public string Email;
}
Tieto triedy slúžia hlavne na držanie dát (vlastností). Zatiaľ o sebe navzájom nič nevedia.
Produkt reprezentuje tovar v obchode, Zakaznik človeka, ktorý nakupuje. Najprv vlastnosti (Nazov, Cena), potom metóda DajInfo, ktorá vráti text o produkte. Pozn.: na slovenskom Windows vypíše DajInfo() desatinnú čiarku, napr. „Mlieko (1,2 EUR)“, hoci v kóde píšeme 1.20 s bodkou.

Časť 3 · Trieda, ktorá to spája

Objednavka: vlastnosti


public class Objednavka
{
    // 1. Väzba na iný objekt
    public Zakaznik Vlastnik;

    // 2. Zoznam objektov (košík)
    public List<Produkt> Polozky = new List<Produkt>();

    // 3. a 4. metódy sú na ďalšom slajde
}
Riadok 4 · väzba na objekt

Typ vlastnosti je naša vlastná trieda Zakaznik. Objednávka má svojho vlastníka.

Riadok 7 · zoznam objektov

Košík: do zoznamu Polozky sa zmestí ľubovoľný počet produktov.

Pozor

Zoznam musíme vytvoriť cez new List<Produkt>(). Inak by bol null a program by spadol.

Kľúčový moment: typ vlastnosti nemusí byť len string alebo double, môže to byť aj naša vlastná trieda. Vlastnik je typu Zakaznik, Polozky je zoznam objektov typu Produkt. Inicializácia new List je dôležitá. K tejto chybe sa vrátime v časti 5.

Časť 3 · Trieda, ktorá to spája

Objednavka: metódy


// 3. Metóda na pridanie tovaru
public void PridajDoKosika(Produkt p)
{
    Polozky.Add(p);
    Console.WriteLine($"Do košíka pridané: {p.Nazov}");
}

// 4. Metóda na výpočet sumy
public double SpocitajSumu()
{
    double spolu = 0;
    foreach (Produkt p in Polozky)
    {
        spolu = spolu + p.Cena; // Čítame cenu z inej triedy
    }
    return spolu;
}
Riadok 2 · objekt ako parameter

Vstupom je celý objekt typu Produkt, nie len jeho názov.

Riadky 4–5

Produkt uložíme do zoznamu a z objektu p prečítame jeho Nazov.

Riadky 11–15 · interakcia

foreach prejde všetky produkty v košíku. Cenu p.Cena čítame z inej triedy.

Riadok 16

return vráti výsledok tomu, kto metódu zavolal.

PridajDoKosika dostane celý objekt Produkt. SpocitajSumu prejde zoznam tejto objednávky a sčíta ceny produktov. Toto je interakcia: Objednavka číta údaje z objektov inej triedy.

Časť 5 · Na čo si dať pozor

Chyba 1Nenastavený objekt


Objednavka mojaObjednavka = new Objednavka();
// mojaObjednavka.Vlastnik = jozko;    ← tento riadok chýba

Console.WriteLine(mojaObjednavka.Vlastnik.Meno);
mojaObjednavka : Objednavka
Vlastnik =
null
Polozky =
List<Produkt>Count = 0
prázdny zoznam
Konzola
Unhandled exception. System.NullReferenceException: Object reference not set to an instance of an object.
at Program.Main(String[] args)

Prečo? Vlastník je prázdny (null), takže počítač nevie, koho meno má vypísať. Riešenie: objekt najprv priraď, až potom ho používaj.

NullReferenceException: mojaObjednavka.Vlastnik.Meno spadne, ak sme zabudli riadok mojaObjednavka.Vlastnik = jozko;. Hlásenie v konzole je skutočný výstup .NET (overené spustením). Môžete ukázať aj ochranu: if (mojaObjednavka.Vlastnik != null) { ... }

Časť 5 · Na čo si dať pozor

Chyba 2Zabudnutý new List

✗Zle

public List<Produkt> Polozky;
Polozky.Add(p) → NullReferenceException
✓Správne

public List<Produkt> Polozky = new List<Produkt>();
Polozky.Add(p) → funguje, produkt je v košíku
Bez new máš iba nálepku s nápisom „košík“, ale žiadny košík. Zoznam sa musí najprv vytvoriť v pamäti.
Ak v triede Objednavka napíšeme len public List<Produkt> Polozky; bez = new List<Produkt>();, pri pokuse pridať tovar program spadne. Aj táto chyba je overená spustením.

Čo si zapamätať

Každá trieda má jednu zodpovednosť
Produkt · Zakaznik · Objednavka

public Zakaznik Vlastnik;

Opakovanie

Rýchly kvíz

1

Čo vypíše mojaObjednavka.Vlastnik.Email?

jozko@email.sk

2

Prečo metóda SpocitajSumu() nepatrí do triedy Produkt?

Produkt pozná len svoju cenu. Zoznam všetkých produktov má Objednavka.

3

Program spadne s NullReferenceException hneď pri Polozky.Add(p). Čo sme zabudli?

Vytvoriť zoznam: = new List<Produkt>();

Precvičovanie

Vyskúšaj si

  1. Do triedy Objednavka pridaj metódu VypisKosik(), ktorá vypíše každý produkt pomocou p.DajInfo().
  2. Pridaj do košíka tretí produkt a over, že sa celková cena zmenila.
  3. Bonus: pridaj do triedy Zakaznik vlastnosť Adresa a vypíš ju spolu s menom vlastníka objednávky.
Riešenie úlohy 1: public void VypisKosik() { foreach (Produkt p in Polozky) { Console.WriteLine(p.DajInfo()); } } Na slovenskom Windows vypíše: Mlieko (1,2 EUR), Chlieb (1,8 EUR).
