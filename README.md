# Spolupráca viacerých tried

Prezentácia na hodinu C#: kompozícia (skladanie objektov) na príklade tried `Produkt`, `Zakaznik` a `Objednavka`.

**Prezentácia:** https://ivanjanovicdigi.github.io/ClassesColaboration/

Ovládanie: šípky = listovanie, Esc = prehľad slajdov, F = celá obrazovka, S = poznámky, T = svetlá/tmavá téma.

Vytvorené v [reveal.js](https://revealjs.com/).
